# Tourfecto — قائمة الأعمال المتبقية (لم تُنفَّذ في هذه الحزمة)

## P0 — يجب تشخيصها قبل إطلاق الخدمات أو تصوير فيديو Meta لها
- [ ] خطأ نشر الحملات إلى Meta: حفظ تفاصيل استجابة Graph API الآمنة، تتبع مرحلة الفشل ومنع تكرار الإنشاء الجزئي عند إعادة المحاولة.
- [ ] فحص ضمان PAUSED على Campaign/Ad Set/Ad بعد النشر المباشر، وتطوير عملية التفعيل المتعمد لكافة المستويات.
- [ ] إصلاح فرق الميزانية USD / EGP والتحقق من حساب Meta والعملات ووحداتها وحدود الميزانية.
- [ ] إصلاح روابط وسائط Instagram والـ robots وContent-Type والتحميل القابل للوصول من Meta؛ اختبار الصور والفيديو والـReels.
- [ ] فحص أسباب Needs reconnecting لكل صفحة وتجديد التفويض الآمن، وإظهار السبب دون تسريب رموز الوصول.
- [ ] إصلاح تقارير التفاعل الصفرية رغم أن Graph API أعاد 76 إعجابًا و10 تعليقات لأحد المنشورات.
- [ ] حصر الأذونات المستخدمة ومطابقتها مع Meta App Review، بما فيها pages_read_user_content وpages_manage_engagement وbusiness_management.

## P1 — وظائف إنتاجية
- [ ] استيراد منشورات Facebook/Instagram السابقة (Historical Social Posts Sync) بالترقيم والدفعات والاستئناف وتفادي التكرار.
- [ ] إظهار الوسائط والوقت والمصدر Imported from Meta وربطها بالتقويم والتقارير.
- [ ] جلب أعداد الإعجابات والتعليقات والمشاركات وReach حيث يتوفر؛ تمييز البيانات غير المتاحة عن الصفر.
- [ ] مزامنة التفاعل الدورية وعرض فترة القياس وتاريخ آخر تحديث وأخطاء الصلاحيات.
- [ ] إظهار اسم صاحب التعليق عندما تسمح به استجابة Meta بدل User.
- [ ] ضبط الردود العامة والخاصة واختبار صلاحيات Meta، ومنع الرد المكرر وسجل كامل لحالة التنفيذ.
- [ ] الرد التلقائي المشروط بالموافقة، والفصل عن Suggest reply وتحويل الشكاوى والأسعار المجهولة للمراجعة.
- [ ] إضافة اختبارات متعددة اللغات للهجات العربية واللغات الأوروبية وعدم اختراع الأسعار أو التوافر.
- [ ] ربط حقائق الشركة وأسعار الرحلات المعتمدة بردود الذكاء الاصطناعي.
- [ ] عرض Business Portfolios وصفحات Facebook والحسابات الإعلانية ومالكيها والصلاحيات في Integrations.
- [ ] دعم استيراد وسائط Instagram السابقة وربطها بالحساب المناسب.
- [ ] إظهار الحالة الحقيقية للحملات: ACTIVE الإداري لا يساوي Delivering، مع آخر نشاط والتاريخ.
- [ ] إصلاح التصفية وقائمة الحملات التاريخية وعمليات المزامنة والعرض في UI.
- [ ] إكمال تقارير Spend/CTR/CPC/CPM/Conversions/ROAS من بيانات حقيقية ومعالجة العملات.
- [ ] تصميم مسار إنشاء Meta حقيقي مع اختيار جمهور/أصول/Creative وشرح حالات الرفض من API.

## P2 — UX وتحسينات
- [ ] إزالة مزج العربية والإنجليزية من واجهة الإعلانات الإنجليزية.
- [ ] فصل أدوات Keywords/UTM/Landing-page عن التحكم الفعلي في الحملات.
- [ ] سجل تغييرات مفصل قابل للتدقيق لكل إجراء نشر/إيقاف/رد.
- [ ] تحسين رسائل الأخطاء الموجهة للعميل وإخفاء التفاصيل الحساسة.
- [ ] زيادة تغطية اختبارات PHP والتكامل ومحاكاة API وإضافة خطة rollback.

## التحقق قبل اعتبار أي بند مكتمل
- اختبار على نسخة staging وببيانات فعلية ومحددة الصلاحيات.
- مقارنة النتائج مع Meta Business Suite/Graph API وليس الاكتفاء بحالة Connected.
- عدم تشغيل إعلان أو إرسال رسالة علنية تلقائيًا دون تفويض واضح من صاحب الحساب.
