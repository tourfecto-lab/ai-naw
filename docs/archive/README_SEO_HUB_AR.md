# تبسيط خدمة السيو (مركز السيو)

## الرفع
1. ارفع الملف tourfecto-seo-hub.zip على فولدر الموقع الرئيسي (اللي فيه app و public_html).
2. اعمل Unzip ووافق على استبدال الملفات.
3. اعمل Reload لـ PHP 8.4.
مفيش قاعدة بيانات ولا SQL.

## اللي اتغير
- القايمة: كل صفحات السيو (13 صفحة) بقت مدخل واحد "مركز السيو" + "جوجل بيزنس".
- فوق كل صفحة سيو: 5 تبويبات (نظرة عامة، الفحص والخطة، الكلمات والمنافسين، المحتوى والتنفيذ، الظهور في الذكاء الاصطناعي) + زرار الإعدادات والربط.
- الروابط القديمة كلها شغالة زي ما هي.
- صفحة خبير السيو: الملخص لوحده أو صفحة الخبير لوحدها (مش الاتنين مع بعض)، قايمة الدورات مرة واحدة، أزرار المطورين اتشالت، والكلام التقني اتكتب ببساطة.
- النتايج: كارت واحد لكل صفحة بأرقام قبل وبعد، وزرار تحديث واحد.
- جوجل بيزنس: 4 تبويبات بدل 12 قسم ورا بعض.
- جديد في الملخص: قايمة "مستني موافقتك"، تنبيه لما ترتيب كلمة ينزل، والتقرير الشهري (افتحه PDF أو يوصلك بالإيميل).
