# مراجعة المنصة قبل بناء العقل الاستراتيجي

التاريخ: 2026-10-29 · البيئة: tourfectoai.pro (بيئة التطوير، بتنزل تلقائيًا من `main`) · حساب عميل تجريبي (موقع #33).

## طريقة المراجعة
- **فحص كل صفحات العميل (50 صفحة من `ClientNavigation`):** الـ50 كلهم ردّوا 200، ومفيش أخطاء JavaScript ولا طلبات API فاشلة وقت الفتح.
  ده بيثبت إن الصفحة بتفتح بس، مش إن الميزة بتشتغل.
- **تجربة فعلية بزراير حقيقية** لخدمات السيو كلها (PRs ‎#3 لـ ‎#8)، وقراءة كود الخدمات اللي العقل هيعتمد عليها.
- اللي مكتوب عليه "ما اتجرّبش" معناه إنه بيفتح بس، ومش متأكدين إنه شغال.

| الخدمة | الدليل |

| الفحص السريع للموقع (Website Optimizer) | تدقيقين حقيقيين (#109، #110) بنتيجة 97.3 |

## 2) موجود بس ناقص أو واقف
| الخدمة | المشكلة |
|---|---|
| قياس الكلمات، والمقالات الأسبوعية، وقياس الخرائط، ومقارنة الروابط | **واقفين لكل العملاء:** ميزانية DataForSEO الشهرية للمنصة خلصت (`seo_monthly_budget_reached`)، ورفعها إعداد أدمن |
| حملات المحتوى | فحص المدة كان بيرفض كل المقالات (اتصلح في ‎#7)، ولسه معتمدة على ميزانية البيانات |
| قياس الظهور في الذكاء الاصطناعي | الأسئلة اتعمدت، لكن لسه ما حصلش قياس فعلي (مجدول) |
| فرص ومخاطر "مستشار المدير التنفيذي" | الجداول (`ceo_growth_opportunities`، `ceo_risk_alerts`) موجودة، بس **محدش بيكتب فيها تلقائيًا**، فاللوحة فاضية دايمًا |
| مركز الإجراءات `ActionCenterService` | بيجمع التوصيات في قايمة واحدة، لكن **مفيش قياس للنتيجة بعد التنفيذ** |
| صفحة النمو | "إجراءات هذا الأسبوع" بتكرر نفس الـ3 إجراءات 3 مرات |
| حلقة التعلم `LearningLoopService` | شغالة للشات بس (فجوات المعرفة)، ومش موجودة للتسويق |
| إعداد مزوّدي الذكاء الاصطناعي وحدود التكلفة | من `.env` بس؛ **مفيش واجهة أدمن** |
| مهام الخطة اللي بيكتبها الذكاء الاصطناعي | بتتكتب بلغة الموقع مش بلغة العميل (الملخص بس اللي اتعالج) |

## 3) بيفتح بس ما اتجرّبش
- **الإعلانات:** فيه إنفاق تراكمي مسجّل (7,514.64$).
- **واتساب والشات وتسويق واتساب:** ممنوع نلمس مسارات Meta طول ما المراجعة شغالة.
- **حاجات تانية:** الحجوزات والمدفوعات، وتسويق البريد، والسوشيال (النشر)، واستوديو التصميم، ومنشئ المواقع، وCRM، والوكالات، والأتمتة، والتشغيل، وذكاء الإيرادات.

## 4) ناقص ومطلوب للعقل الاستراتيجي
1. **نموذج موحّد لكل شركة:** البيانات متفرقة في كذا جدول. مفيش مكان واحد يقول "العقل فاهم إيه عن الشركة دي وناقصه إيه".
2. **قرارات بأدلة بتنسّق بين الخدمات:** كل خدمة شغالة لوحدها. مفيش طبقة بتقرر "الأولوية دلوقتي السيو ولا الإعلانات ولا السمعة" بناءً على هدف الشركة.
3. **حلقة كاملة:** قرار ← موافقة ← تنفيذ ← قياس قبل وبعد ← تعلّم. غير موجودة لأي خدمة غير الشات.
4. **ذكاء مشترك بين الشركات:** نتايج مجمّعة ومن غير هوية، وبموافقة الشركات. غير موجود.
5. **ذكاء السوق:** اتجاهات السياحة، ومؤشرات الاقتصاد، والطلب، من مصادر موثّقة. غير موجود، ومحتاج تحديد مصادر بيانات.
6. **توصيات النمو:** باقات جديدة، وأسواق جديدة، وتسعير. موجود جزء بسيط في `GrowthSignals` (الرحلات اللي نركّز عليها).
7. **"Strategic Radar":** مفيش ميزة بالاسم ده في الكود. أقرب حاجة ليها اللوحة التنفيذية وصفحة النمو.
8. **لوحة أدمن** لمزوّدي الذكاء الاصطناعي، والتكاليف، والحدود، والصلاحيات.

## قرارات التصميم
- **العقل بيقرا من الجداول الموجودة،** ومش بيكرر أي خدمة. كل قرار ليه رابط للخدمة اللي بتنفّذه.
- **العزل:** كل استعلام بيتقيّد بـ `user_id`، وبـ `website_id` لما يكون فيه موقع، والموقع بيتأكد إنه ملك المستخدم الأول.
- **مفيش أرقام مخترعة:** القرار بيتولد بس لما فيه دليل محسوب، والدليل بيتحفظ معاه.
- **الصرف:** أي قرار فيه صرف فلوس أو تغيير حساس بيفضل "مقترح" لحد ما صاحب الشركة يوافق. والتنفيذ نفسه بيتم من خلال الخدمة الموجودة بنفس ضماناتها.
